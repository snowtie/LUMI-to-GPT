LUMI to GPT
===========

이 항목은 LUMI Chat의 ChatGPT OAuth 연결 확장 모드입니다.
LUMI Chat을 먼저 구독하고 Little LUMI를 한 번 실행해야 합니다.
STUDIO LUMI, LUMI Chat 제작자 또는 OpenAI의 공식 제품이 아닌 비공식 커뮤니티 확장입니다.

설치
1. LUMI Chat과 이 항목을 모두 구독합니다.
2. Little LUMI를 한 번 실행한 뒤 종료합니다.
3. LUMI-to-GPT\INSTALL.cmd를 실행하고 GPT 애드온만, LUMI TTS 포함, 기존 설치에 TTS만 추가 중 하나를 고릅니다.
4. Little LUMI와 바탕화면의 LUMI to GPT를 실행합니다.
5. ChatGPT 계정 연결을 누르고 브라우저 로그인을 완료합니다.
6. Little LUMI의 루미 AI 설정에서 두뇌는 ChatGPT (OAuth), 목소리는 필요하면 GPT-SoVITS를 선택합니다.
7. 꼬미의 기존 말 걸기 창에서 대화합니다.

기본 모델은 GPT-5.6 Luna이며 혼잣말과 화면 구경은 처음부터 꺼져 있습니다.
대화는 일반 ChatGPT 웹 메시지가 아니라 로그인한 계정의 Codex 사용량을 씁니다.
LUMI Chat이 대화창, 기억, 페르소나와 말풍선을 담당합니다.
이 확장은 공식 Codex App Server 연결, 말풍선 안정화, 절전형 로컬 GPT-SoVITS 목소리와 Codex MCP를 추가합니다.
계정 창에서 새 GitHub 배포 버전을 자동으로 확인하며, 설치 오류는 %LOCALAPPDATA%\LumiToGPT\logs에 자세히 남습니다.
